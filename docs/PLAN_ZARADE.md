# Plan zarade

Glavni vodič je u aplikaciji (kartica *Vodiči → Kako zaraditi*) i u datoteci
[karte/data/guides/8_kako_zaraditi.md](../karte/data/guides/8_kako_zaraditi.md): koliko se realno zarađuje (Which?, Vanderbilt,
US Senat), pravilo palca za odnos preprodajne i nominalne cijene, pet načina zarade (presale, regionalna arbitraža, domaće zvijezde,
partnerski programi, sport), upravljanje kapitalom, kada kupiti i prodati, karta tržišta, strani prodavači i plan za prvih 30 dana.

Alati u aplikaciji:

```bash
karte plan                 # raspodjela budžeta, raspon ishoda (4.000 simulacija), kalendar radnji
karte plan --budget 1500 --countries europa
karte gui                  # kartica "Plan zarade" + gumbi "Provjeri cijene i dostupnost" za svaki događaj
```
